# Mi primera página web

Proyecto sencillo de una página web interactiva, creada con HTML, CSS y JavaScript. Incluye además un pequeño script de Python para calcular la media de una lista de números.

## Funcionalidades

- Muestra un saludo y permite cambiar el mensaje con el botón **Salúdame**.
- Alterna entre tema claro y oscuro.
- Muestra un reloj analógico que se actualiza cada segundo.
- Adapta el diseño a pantallas pequeñas.
- Incluye un script de Python que calcula la media aritmética de una lista.

## Tecnologías

- HTML5
- CSS3
- JavaScript (sin frameworks ni dependencias)
- Python 3 (para el script auxiliar)

## Cómo ejecutar la página

No es necesario instalar dependencias ni compilar el proyecto. Abre `index.html` en un navegador web.

## Cómo ejecutar el script de Python

Desde la carpeta del proyecto, ejecuta:

```bash
python calculadora.py
```

El script calcula la media de una lista de ejemplo y muestra el resultado en la terminal. No forma parte de la página web.
