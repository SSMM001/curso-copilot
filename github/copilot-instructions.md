# Instrucciones del proyecto

## Estructura y tecnologías

- Mantén la web en HTML, CSS y JavaScript nativos; no añadas frameworks ni dependencias sin necesidad.
- Conserva las responsabilidades separadas: `index.html` para la estructura, `style.css` para presentación y `main.js` para las interacciones.
- `calculadora.py` es un ejemplo independiente de la web. Mantén las funciones nuevas de Python separadas de la aplicación web.

## Implementación

- Sigue el idioma y los patrones existentes: interfaz y contenido en español, nombres de clases y variables descriptivos.
- Mantén la página adaptable a móviles y conserva la accesibilidad existente, incluidos los controles semánticos y sus etiquetas.
- Para cambios visuales, comprueba los temas claro y oscuro y los estados interactivos de los botones.
- Evita agregar pasos de compilación o instalación: la página se ejecuta abriendo `index.html` en un navegador.

## Validación

- Para cambios en la web, abre `index.html` y comprueba las interacciones afectadas en un navegador.
- Para cambios en el script de Python, ejecuta `python calculadora.py` desde la carpeta del proyecto.
- Actualiza `README.md` cuando cambien las funcionalidades o las instrucciones de ejecución.
